What it checks

Six rules, linter as you type.

Chapter Check watches the description editor in YouTube Studio and re-lints on every keystroke. Each violation names the exact line and the rule it broke, so you fix the right thing the first time.

R1
First timestamp must be 0:00
YouTube requires the first chapter to start at zero.
R2
At least 3 chapters
Fewer than 3 timestamps and the chapter rail will not activate.
R3
Each chapter at least 10 seconds
Adjacent timestamps less than 10 seconds apart are rejected.
R4
Strictly ascending
A timestamp that goes backward breaks the sequence.
R5
Colon timecode format
M:SS, MM:SS, or H:MM:SS at the start of the line.

Built to respect your studio

Read-only, by design.

Chapter Check reads the description text in your tab to lint it. It never writes to the page, never submits the form, and never auto-corrects timestamps. You fix the line yourself.

No tracking, no analytics No accounts, no cloud Manifest V3, no remote code Never edits the host page

Chapter Check is built in public by one solo developer at github.com/theluckystrike. The code is small enough to read in an afternoon. There is no server, no sync, no data collection. The description text is read in your tab to lint it and never leaves your device.
